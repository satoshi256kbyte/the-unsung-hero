# 進捗ダイスと経験値

## 進捗ダイスの計算

毎ターンの進捗上昇量は、技・体をベースにしたランダム計算に、
ランダムイベントによる補正を加えて決まる。

- 技が高いほど、ダイスは計画値付近で「高止まり」しやすい（上振れ側が安定する）
- 体が低いほど、ダイスは下振れしやすい（下振れ側に偏る）
- 心は進捗ダイスの計算には関与せず、ネガティブイベントの発生確率を左右することで
  間接的に進捗へ影響する

ランダムイベントが進捗にどう関与するか（ダイスの補正なのか、タスク状態そのものの書き換えなのか）は
[ターン処理フロー](./ターン処理フロー.md) を参照。

## 経験値の蓄積とレベルアップ

技（レベル）の基本仕様は [メンバー](../02-基本設計/メンバー.md) の
「技（レベル）と経験値」を参照。ここでは計算に関わる詳細を補足する。

- 経験値はタスクをこなすことで蓄積する
- 技が低いメンバーほど、同じ量のタスクをこなした際に蓄積する経験値が多い
  （＝レベルが上がりやすい）
- カード「教育」「ペアプログラミング」は経験値の蓄積を早めるブースト
  （具体的な付与量は今後調整。詳細は [カード](./カード.md) を参照）
- レベルアップの速度はかなり遅く、技4以下のメンバーでも
  1ヶ月ステージを通して1程度しか上がらない想定

### 未決定事項

- 技が上がるにつれ必要経験値がどう増えるかの具体的なカーブ
  （最大値99までの全体の伸び方）
- タスク完了時に得られる経験値の基準値
- 教育・ペアプログラミングによる経験値付与量
- 技の最大値が99に定まったことに伴う、
  進捗ダイスの計算（技による「高止まり」の度合い）の具体的な閾値
