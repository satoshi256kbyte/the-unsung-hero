# カード

基本的なコスト消費・配布ルールは [ターン制とカード](../02-基本設計/ターン制とカード.md) を参照。
ここでは個別のカードの種類と効果を整理する。

## カードの大分類

育成系・定例系・メンタル系・休息系・ハイリスク調整系など、
カードの大分類は一覧が揃ってから改めて整理する。

## カードの適用方式

カードを使うことはメンバー（またはPM自身）への「指示」であり、
単発の効果を発生させるものと、指示として状態をセットし続けるものがある。
考え方の詳細は [ターン制とカード](../02-基本設計/ターン制とカード.md) の
「カードの適用イメージ」を参照。

| 適用方式 | 説明 |
|---------|------|
| 即時 | カード使用時に1回だけ効果が発生する（結果として別の状態を誘発する場合もある） |
| セット・自動解除 | 状態がセットされ、条件達成（期間終了・タスク完了など）で自動的に解除される |
| セット・手動解除 | 状態がセットされ、別のカードで解除するまで継続する |

## カードの効果例

コストはすべて仮の目安（低・中・高・特大の4段階）であり、具体的な数値は後で調整する。

| カード名 | 効果 | 適用方式 | コスト(仮) | 説明 |
|---------|------|---------|-----------|------|
| デイリー | ランダムイベント（手戻り・停滞）の発生確率を下げる | セット・手動解除 | 低 | PMの理想形（デフォルトの1日の行動）の1つ。固定イベント「デイリー」（毎ターン発生するチェックポイント）に対応するカード。ステージ開始時点でガントチャートに組み込まれた既定行動であり、通常は追加コストなしに毎日自動継続する。他のカードへの入れ替えは当日限りの措置で、翌日には自動的にデイリーへ戻る。この既定状態自体を（入れ替えではなく）複数日にわたって止めたい場合は「デイリー中止」を使う |
| デイリー中止 | 「デイリー」の既定状態を解除する | 即時 | 低 | 単発の入れ替えとは異なり、複数日にわたってデイリーを止めたいときに使う。再開するには改めて「デイリー」を使う |
| レビュー | 手戻りの発生確率を下げる | セット・手動解除 | 低 | PMの理想形の1つ。タスクの品質確認を行う。コスト・入れ替えの扱いは「デイリー」と同様（詳細は [ターン制とカード](../02-基本設計/ターン制とカード.md) の「PMの理想形」を参照） |
| モニタリング | 検収不合格・過大報告・過小報告・報告漏れの発生確率を下げる | セット・手動解除 | 低 | PMの理想形の1つ。メンバーの状況を確認し、実態と報告のズレを早期に掴んで最終検収での手痛い発覚を防ぐ。コスト・入れ替えの扱いは「デイリー」と同様 |
| サマライズ | 締めの発生確率を下げる | セット・手動解除 | 低 | PMの理想形の1つ。週次進捗会議・工程の締めに備えた報告資料を準備する。コスト・入れ替えの扱いは「デイリー」と同様 |
| 臨時MTG | キックオフ・クロージング・週次進捗会議のランダムイベントの発生確率を一時的に下げる | 要検討 | 要検討 | デイリーとは別枠の、必要時に招集する会議カード。これらの固定イベントのリスクが高まった場面で、デイリーによる基本の低減だけでは足りない分を補う |
| 臨時モニタリング | キックオフ・クロージング・週次進捗会議のランダムイベントの発生確率を一時的に下げる | 要検討 | 要検討 | モニタリングによる基本の低減だけでは足りない場面で、追加のカバーとして使う |
| 臨時サマライズ | キックオフ・クロージング・週次進捗会議のランダムイベントの発生確率を一時的に下げる | 要検討 | 要検討 | サマライズによる基本の低減だけでは足りない場面で、追加のカバーとして使う |
| 教育 | 対象メンバーの経験値が増加する（技を直接上げるのではなく、レベルアップを早めるブースト） | 即時 | 中 | 教育する側・される側の両方に「トレーニング停滞」が確定で発生する（詳細は [イベント](./イベント.md) の「手戻り・停滞」を参照）。経験値の付与量は今後調整 |
| ペアプログラミング | 対象メンバーの経験値が増加する（教育と同様、技を直接上げるのではなくブースト） | 即時 | 中 | 教育と同系統の育成カード。教育よりコスト・効果ともに軽めの想定。同様に両者に「トレーニング停滞」が発生する |
| 雑談 | 「心」の低下率を低減する | 要検討 | 低 | 回復ではなく減衰の緩和。効果の持続期間は未確定 |
| 個別面談 | 対象メンバー1人の「心」を軽度に回復させる | 即時 | 低〜中 | 雑談より対象を絞った深めのフォローという位置づけ |
| 表彰 | 対象メンバーの「心」を大きく回復させる | 即時 | 中 | ステージ中の配布数が限定されるカードの想定 |
| 計画休 | 対象メンバー1人の「心」「体」が一定値回復する | 即時 | 中 | |
| 残業許可 | PM・メンバー全員の1日のコスト上限を引き上げる（例: 8→10） | セット・自動解除 | 低（1） | 残業申請を出すイメージ。1枚で全員に一括適用される。効果は申請の翌日から発生し、1ヶ月間持続したのち自動的に元に戻る。上限拡張分を実際に使った日は、その分バッファから追加消費される |
| 休出 | 一定期間、週末も進捗・イベント発生が継続するようになる | セット・自動解除 | 特大 | 設定した期間が終われば自動的に解除される想定。チームメンバーの心体が低下、ネガティブイベントの発生確率が上昇する |
| リスケ | 事前作成データの「リスケ後ガントチャート」に差し替える | 即時 | 中 | ガントチャートの構造変更は事前作成データへの差し替えで行う |
| 交渉 | 顧客と交渉する。使用時に「納期延期」「スコープ削減」のいずれかを選ぶ | 即時 | 特大（40程度、要調整） | 必ず成功するとは限らない。納期がひっ迫していれば延期、残タスクが多すぎればスコープ削減、というように状況に応じて選ぶカード。納期延期を選んだ場合はメンバーの心・体も回復し、延期できる幅は予算バッファで支えられる分に自動的にキャップされる |
| メンバー追加 | メンバーを1人追加・補充する（最大6人） | 即時 | 高 | 新規メンバーは「技」が低い状態で参加し、既存メンバーの誰かに強制イベント「オンボーディング」（停滞状態）が発生する |
| 進捗ブースト | 対象タスクの進捗効率を無理やり上げる | 要検討 | 中〜高 | 手戻りの解消にも使用できる、手戻り専用ではない汎用カード |
| タスク再割当て | あるタスクの担当メンバーを変更する | 即時 | 低 | 技が低いメンバーへの再割当てでは、進捗が計画値から離れやすくなりやすい |
| 停滞対応 | 対象タスクの停滞を解除する。純粋停滞なら本人へ、ブロッカー停滞ならブロッカータスクの担当メンバーへ働きかける | 即時 | 低 | 停滞の原因が誰にあるか（メンバー本人か、ブロッカータスクの担当者か）に応じて働きかける相手を選ぶカード |
| 強制締め | 未完了のまま該当工程の「締め」を完了させる | 即時 | 高 | 固定イベント「締め」が完了しない状態を強制的に解消するカード。使用後は手戻りの発生確率が大きく上昇する |

## 未決定・要検討事項

- カードの大分類
- カードごとの具体的なコスト数値のバランス調整（「交渉」の40コストなど、上表のコストはすべて仮）
- 「雑談」「進捗ブースト」「臨時MTG」「臨時モニタリング」「臨時サマライズ」の
  適用方式（即時かセット型か）・コスト・持続期間
- デイリー・モニタリング・サマライズによるキックオフ・クロージング・週次進捗会議のリスク低減の具体的な配分、
  および「臨時MTG」「臨時モニタリング」「臨時サマライズ」それぞれの効果の違い
- 「交渉」カードで選ぶ効果（スコープ削減）の失敗時のペナルティ内容
- 上記以外のランダムイベント・カードの一覧化
- 「デイリー」のみ既定状態を止める専用カード（デイリー中止）を持つ非対称について、
  レビュー・モニタリング・サマライズにも同様の専用カードを用意するか、それとも不要か
