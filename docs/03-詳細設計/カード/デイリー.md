# デイリー

| 項目 | 内容 |
| ---- | ---- |
| 効果 | ランダムイベント（手戻り・停滞）の発生確率を下げる |
| 適用方式 | セット・手動解除 |
| コスト（仮） | 低 |

PMの理想形（デフォルトの1日の行動）の1つ。固定イベント「デイリー」（毎ターン発生する
チェックポイント）に対応するカード。ステージ開始時点でガントチャートに組み込まれた
既定行動であり、通常は追加コストなしに毎日自動継続する。他のカードへの入れ替えは
当日限りの措置で、翌日には自動的にデイリーへ戻る。この既定状態自体を（入れ替えではなく）
複数日にわたって止めたい場合は「デイリー中止」を使う。
