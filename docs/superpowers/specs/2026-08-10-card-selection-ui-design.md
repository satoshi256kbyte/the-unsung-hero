# カード選択UI設計

## 概要

PMがカードを選ぶ際のドラッグ＆ドロップUIの設計。
「持ってくるだけで勝手に収まる」操作感を実現し、
入れ替えの手間を極限まで減らしつつ、ドロップ位置の選択肢は残す。

## 核心概念：カード枠と状態変化の分離

| 概念 | 役割 | 対象 |
|------|------|------|
| カード枠 | PMのコスト消費の視覚化（今日何に時間を使うか） | PM自身の1日 |
| 状態変化 | カード使用の結果として付与される効果 | メンバーまたはプロジェクト |

- カードを使う＝PMがコストを払って指示を出す行為
- その結果、メンバーまたはプロジェクトに状態変化が付与される
- 状態変化の表示はステータスエリア（メンバーステータス一覧・プロジェクトステータス一覧）で行う
- カード枠から押し出されても、既に付与済みの状態変化は影響を受けない
- ガントチャートは状態変化の対象外。
  変化はタスク増減・スケジュール変更として反映される（リスケカード、仕様追加イベント）

## カード枠のレイアウト

8枠を1列に配置。左から右へ優先度順に並ぶ。

```
[デイリー][レビュー][リサーチ][サマライズ][バッファ1][バッファ2][バッファ3][バッファ4]
```

| 枠の種類 | 初期状態 | 特徴 |
|---------|---------|------|
| 既定枠（左4つ） | 対応カードがセット済み | 押し出されても翌日自動復帰 |
| バッファ枠（右4つ） | 空 | 押し出されたカードは消失 |

- 各枠は1コスト分を表す（合計8＝PMの1日のコスト上限）
- 大コストカードは複数枠を占有（例：コスト3なら3枠連続）
- ロック状態：翌日以降も占有し続けるカードは枠にロックアイコンが付き、
  ドラッグ対象外になる

## ドラッグ＆ドロップの挙動

### 操作フロー

1. ドラッグ開始：手札エリアからカードを掴む
2. ドラッグ中（ホバー）：枠の上を通過するたびにリアルタイムでプレビューアニメーション
   - 挿入位置から右方向にカードがスライド
   - 右端から溢れるカードは半透明＋下にフェードアウトする表現
   - 日跨ぎが発生する場合は吹き出しが出現
3. ドロップ：確定。アニメーション完了後に枠の状態が確定する
4. ドロップキャンセル：枠外にドロップまたはEscで全て元に戻る

### ドミノ倒しのルール

- 挿入位置にカードが入り、右方向に全てシフト
- 大コストカード（N枠占有）は挿入位置からN枠分を確保し、押し出し量もN枠分
- ロック状態の枠は飛ばす（ロック枠の左にシフトが溜まり、ロックの左隣から溢れる）
- 1枠カードでも同じ挙動（swap ではなく insert → shift）

### 吹き出しの表示条件

| 条件 | 吹き出しテキスト例 |
|------|------------------|
| バッファ枠のみ溢れ | （吹き出しなし） |
| 既定枠が1つ以上溢れ | 「今日の〇〇が潰れます」 |
| 翌日に影響 | 「明日にも響きます」 |
| 翌々日以降にも影響 | 「明後日まで響きます」 |

## 日跨ぎの処理

### 発生条件

カードのコストが「挿入位置から右端までの残り枠数」を超える場合、
超過分が翌日以降の枠を食う。

例：コスト12のカードを枠3の位置に挿入した場合

- 当日分：枠3〜枠8の6枠を消費
- 翌日分：残り6コスト分を翌日の枠で消費

### 翌日の枠の食われ方

翌日は既定枠が自動復帰した状態から開始する。
そこに対して右端から食っていく。

犠牲順（右端＝バッファ側から）：

1. バッファ4 → バッファ3 → バッファ2 → バッファ1
2. サマライズ
3. リサーチ
4. デイリー
5. レビュー（最後まで残る）

翌々日以降も同様のルールを繰り返す。

### UIの表現

翌日レーンは画面に表示しない。
ドラッグ中に吹き出しで影響日数だけフィードバックする。

### ロック状態

日跨ぎが発生したカードは、占有しているターン全てでロック状態になる。

- 当日：挿入位置からN枠がロック
- 翌日以降：食われた枠数分がロック（左端から埋まる）
- ロック中の枠はドラッグ不可、暗めの色＋ロックアイコンで表示

### ターン経過による解放

ロック状態のカードはコスト分のターンが経過すると自動解放。
解放された翌日に既定枠が復帰順に従って戻る。

## 復帰ルール

### 既定枠の自動復帰

ターン開始時に、ロックされていない空き枠に既定カードが復帰する。

復帰順：デイリー → レビュー → リサーチ → サマライズ

- 空き枠が4つあれば全て復帰
- 空き枠が2つなら「デイリー」「レビュー」だけ復帰
- 復帰位置は左詰め（枠1から順に埋まる、ロック枠は飛ばす）

### 復帰しないケース

- 「デイリー中止」カードを使った場合、デイリーは復帰対象から外れる（再セットするまで永続）
- 同様の明示的解除手段が他の既定カードに追加された場合も同じ扱い

## 具体例

### 例1：コスト2のカードをバッファ1にドロップ

初期状態：

```
[デイリー][レビュー][リサーチ][サマライズ][空][空][空][空]
```

ドロップ後：

```
[デイリー][レビュー][リサーチ][サマライズ][===カードA===][空][空]
```

カードAが2枠を占有。溢れなし。

### 例2：コスト3のカードをリサーチの位置にドロップ

初期状態：

```
[デイリー][レビュー][リサーチ][サマライズ][カードB][空][空][空]
```

ドロップ後：

```
[デイリー][レビュー][======カードC======][リサーチ][サマライズ][カードB]
```

カードC（3枠）が枠3に挿入され枠3-4-5を占有。
リサーチ→枠6、サマライズ→枠7、カードB→枠8にシフト。
空き枠が吸収されて溢れなし。

### 例3：コスト12のカードを枠1にドロップ（日跨ぎ）

初期状態（全既定枠セット済み、バッファ空）：

```
[デイリー][レビュー][リサーチ][サマライズ][空][空][空][空]
```

当日：

```
[====================カードD====================]
```

全8枠を占有。デイリー・レビュー・リサーチ・サマライズ全て押し出し。
残り4コスト分が翌日に食い込む。

翌日（ロック4枠 + 空き4枠に既定が復帰）：

```
[==ロック==][==ロック==][==ロック==][==ロック==][デイリー][レビュー][リサーチ][サマライズ]
```

吹き出し：「明日にも響きます」
