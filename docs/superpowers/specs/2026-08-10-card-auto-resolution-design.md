# カード自動解決ルール設計

## 概要

全カードの操作を「枠に置くだけ」に統一する。
対象メンバー・対象タスクの選択はカードごとに定義された自動解決ルールで決定し、
プレイヤーによる手動指定を排除する。

## 設計方針

### プレイヤーの判断ポイント

- どのカードを今使うか（タイミング）
- どの枠に置くか（何を犠牲にするか）
- 使わずに温存するか

### プレイヤーがやらないこと

- メンバーを指定する
- タスクを指定する
- 効果の対象を選ぶ

### UIへの影響

カード選択UIの設計（ドラッグ＆ドロップ、ドミノ倒し）はそのまま維持する。
サブアクション・対象選択のモーダルは不要になる。

## 自動解決ルール

### ルールの基本パターン

| パターン | 説明 | 例 |
|---------|------|-----|
| 全体効果 | 対象指定なし、全員またはプロジェクトに効く | デイリー、残業許可、休出 |
| 最弱救済 | パラメータが最も低いメンバーが対象 | 個別面談（心最低）、計画休（体最低） |
| 最適割当 | 状態に最も適したメンバー/タスクが対象 | アサイン、教育（技最低） |
| 状況対応 | 問題が発生しているタスク/メンバーが対象 | 停滞対応、進捗ブースト |

### 全カードの自動解決ルール一覧

| カード | パターン | 自動解決ルール |
|--------|---------|--------------|
| デイリー | 全体効果 | 対象指定なし |
| レビュー | 全体効果 | 対象指定なし |
| モニタリング | 全体効果 | 対象指定なし |
| サマライズ | 全体効果 | 対象指定なし |
| 臨時MTG | 全体効果 | 対象指定なし |
| 臨時モニタリング | 全体効果 | 対象指定なし |
| 臨時サマライズ | 全体効果 | 対象指定なし |
| 残業許可 | 全体効果 | 全員一括 |
| 休出 | 全体効果 | 全員一括 |
| 教育 | 最適割当 | 技が最も低いメンバーを対象に、技が最も高いメンバーが教える |
| ペアプログラミング | 最適割当 | 技が最も低いメンバーを対象に、技が次に高いメンバーとペアを組む |
| 雑談 | 全体効果 | 対象指定なし（チーム全体への効果） |
| 個別面談 | 最弱救済 | 心が最も低いメンバーが対象 |
| 表彰 | 最弱救済 | 心が最も低いメンバーが対象 |
| 計画休 | 最弱救済 | 体が最も低いメンバーが対象 |
| アサイン | 最適割当 | 担当タスクが最も少ないメンバーを新規タスクにアサイン |
| 入れ替え | 最適割当 | 進捗最大メンバーの最進捗タスクと、進捗最小メンバーの最低進捗タスクを交換 |
| 巻取り | 最適割当 | 進捗最大メンバーが、進捗最小メンバーの最低進捗タスクを完全に引き取る |
| 停滞対応 | 状況対応 | 停滞中タスクのうち最も遅れているものが対象 |
| 進捗ブースト | 状況対応 | 計画比で最も遅れているタスクが対象 |
| リスケ | 全体効果 | 事前データへ差し替え（対象指定なし） |
| 納期交渉 | 全体効果 | 顧客と納期延期を交渉する。成功すれば納期延長＋メンバーの心・体回復。延期幅は予算バッファにキャップ |
| スコープ交渉 | 全体効果 | 顧客とスコープ削減を交渉する。成功すれば未着手タスクの一部が削除される |
| メンバー追加 | 全体効果 | 追加メンバーの技は固定値、オンボーディング対象は技が最も高いメンバー |
| 強制締め | 状況対応 | 現在の工程の締めが対象（一意に決まる） |
| デイリー中止 | 全体効果 | 対象指定なし |

### 用語の定義

| 用語 | 定義 |
|------|------|
| 進捗最大メンバー | 担当タスクの進捗率の平均が最も高いメンバー |
| 進捗最小メンバー | 担当タスクの進捗率の平均が最も低いメンバー |
| 最進捗タスク | そのメンバーの担当タスクのうち進捗率が最も高いもの |
| 最低進捗タスク | そのメンバーの担当タスクのうち進捗率が最も低いもの |

### タイブレーク

複数メンバー/タスクが同値の場合はメンバーIDの若い順（画面左に表示されている方）を優先する。
タスクが同値の場合はガントチャート上で先に開始するものを優先する。
決定論的なルールとし、プレイヤーが予測可能にする。

## 効果プレビューアニメーション

### タイミング

ドラッグ中（ホバー）に、枠のドミノ倒しプレビューと同時に、
メンバーステータスエリアに効果プレビューを表示する。

### 表示要素

| 要素 | 表現 |
|------|------|
| 対象ハイライト | 対象メンバーのアイコン/枠が光る |
| 矢印 | 上矢印（バフ）/ 下矢印（デバフ・コスト） |
| キーワード | 1〜2語で効果を示す（例：「技↑」「心↑」「停滞解除」「タスク移動」） |

### 具体例

| カード | プレビュー表示 |
|--------|--------------|
| 教育 | メンバーA（技最低）に「経験値↑」、メンバーD（技最高）に「停滞」 |
| 個別面談 | メンバーC（心最低）に「心↑」 |
| 巻取り | メンバーD（進捗最大）に「タスク増」、メンバーA（進捗最小）に「タスク減」 |
| 入れ替え | メンバーD↔メンバーA に「タスク交換」の双方向矢印 |
| 残業許可 | 全メンバーに「コスト上限↑」 |
| 計画休 | メンバーB（体最低）に「心↑ 体↑」+「1日休み」 |

### 表示ルール

- ドラッグ中のみ表示、ドロップまたはキャンセルで消える
- 枠のドミノ倒しアニメーションと同時に0.2秒程度のフェードインで出現
- 全体効果の場合は全メンバーにまとめて薄くハイライト
- 特定メンバー対象の場合はそのメンバーだけ強調ハイライト

### 既存UIとの統合

画面構成の課題エリアにメンバーステータスが表示されている想定。
プレビューはそこにオーバーレイする形で統合する。
枠側の「今日の〇〇が潰れます」吹き出しと、メンバー側の効果プレビューが同時に見えることで、
コストと効果の両方を一目で判断できる。

## カードの廃止・新設・分割

### 廃止

| カード | 理由 | 代替 |
|--------|------|------|
| タスク再割当て | 手動でメンバー・タスクを指定する前提のカード | アサイン・入れ替え・巻取り |

### 新設

| カード | 効果 | 適用方式 | コスト(仮) |
|--------|------|---------|-----------|
| アサイン | 担当タスクが最も少ないメンバーを新規タスクにアサインする | 即時 | 低 |
| 入れ替え | 進捗最大メンバーの最進捗タスクと、進捗最小メンバーの最低進捗タスクを交換する | 即時 | 低 |
| 巻取り | 進捗最大メンバーが、進捗最小メンバーの最低進捗タスクを完全に引き取る | 即時 | 低〜中 |

### 分割

| 旧カード | 新カード | 効果 | コスト(仮) |
|---------|---------|------|-----------|
| 交渉 | 納期交渉 | 顧客と納期延期を交渉する。必ず成功するとは限らない | 特大 |
| 交渉 | スコープ交渉 | 顧客とスコープ削減を交渉する。必ず成功するとは限らない | 特大 |
