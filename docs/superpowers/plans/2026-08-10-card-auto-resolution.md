# カード自動解決ルール 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended)
> or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全カードの対象自動解決ルールを設計ドキュメントに反映し、
効果プレビューアニメーションの仕様をUI設計specに追加する。

**Architecture:** ソースコードは存在しない段階のため、
変更対象はすべてMarkdownドキュメント。3つの既存ドキュメントを更新し、
1つのUI設計specにセクションを追加する。

**Tech Stack:** Markdown（markdownlintルール準拠）

## Global Constraints

- Markdown記述は CLAUDE.md に記載の markdownlint ルールに準拠する
- 1行120文字以内（テーブル・コードブロック・見出しは対象外）
- 見出し・リスト・テーブルの前後に空行1行
- 箇条書き＋太字＋コロンの書き方は禁止（2ペア以上並ぶ場合は表にする）
- コミットは Conventional Commits 形式＋日本語

- [ ] **Step 1: 効果プレビューアニメーションセクションを追加する**

ファイル末尾（「例3」セクションの後）に以下のセクションを追加する:

```markdown
## 効果プレビューアニメーション

### タイミング

ドラッグ中（ホバー）に、枠のドミノ倒しプレビューと同時に、
メンバーステータスエリアに効果プレビューを表示する。

### 表示要素

| 要素 | 表現 |
|------|------|
| 対象ハイライト | 対象メンバーのアイコン/枠が光る |
| 矢印 | 上矢印（バフ）/ 下矢印（デバフ・コスト） |
| キーワード | 1〜2語で効果を示す（例：「技↑」「心↑」「停滞解除」「タスク移動」） |

### 具体例

| カード | プレビュー表示 |
|--------|--------------|
| 教育 | メンバーA（技最低）に「経験値↑」、メンバーD（技最高）に「停滞」 |
| 個別面談 | メンバーC（心最低）に「心↑」 |
| 巻取り | メンバーD（進捗最大）に「タスク増」、メンバーA（進捗最小）に「タスク減」 |
| 入れ替え | メンバーD↔メンバーA に「タスク交換」の双方向矢印 |
| 残業許可 | 全メンバーに「コスト上限↑」 |
| 計画休 | メンバーB（体最低）に「心↑ 体↑」+「1日休み」 |

### 表示ルール

- ドラッグ中のみ表示、ドロップまたはキャンセルで消える
- 枠のドミノ倒しアニメーションと同時に0.2秒程度のフェードインで出現
- 全体効果の場合は全メンバーにまとめて薄くハイライト
- 特定メンバー対象の場合はそのメンバーだけ強調ハイライト

### 既存UIとの統合

画面構成の課題エリアにメンバーステータスが表示されている想定。
プレビューはそこにオーバーレイする形で統合する。
枠側の「今日の〇〇が潰れます」吹き出しと、
メンバー側の効果プレビューが同時に見えることで、
コストと効果の両方を一目で判断できる。
```
