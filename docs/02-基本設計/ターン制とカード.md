# ターン制とカード

## 基本ルール

- 1日1ターン制
- PMの行動はカードを選択して決定する
- PMの1日のコストは基本8、カード使用で消費する
- 1ターンに複数枚のカードを使用できるが、合計コストが1日の上限を超える組み合わせは選択不可
- カードはステージ開始時に一定数配布＋ターンごとにランダム配布
- ステージ中1回しか配布されないカードもある
- カードの種類・個別の効果は [カード](../03-詳細設計/カード.md) を参照

## カードの適用イメージ

カードを使うことをメンバーに対する「指示」と捉える。

- カードを使う（指示を出す）と、その時点でPMのコストが1回消費される
- 対象（PM自身、またはメンバー）には、指示に応じた「状態」がセットされる
- 状態が有効な間、対象の挙動が変化する（進捗速度の鈍化・効率アップ、
  心体の増減パターンの変化、固定コストが発生し続けるといった変化も含む）
- 状態はカードの種類によって、条件達成による自動解除、または別カードによる手動解除で終了する
- 1人のメンバーに複数の状態を同時にセットすることも可能
  （例: 「ペースアップ」の指示を出した状態のまま、別途「休み」を指示する）

## PMの理想形（デフォルトの1日の行動）

PMの1日8コストの理想形（デフォルトの行動）は、次の4つで構成される想定。

| 行動 | 主な役割 |
|------|---------|
| デイリー | 日々の進行確認。手戻り・停滞系のランダムイベントの発生確率を下げる |
| レビュー | タスクの品質確認。手戻りの発生確率を下げる |
| モニタリング | メンバーの状況確認。過大報告・過小報告・報告漏れの発生確率を下げる |
| サマライズ | 週次進捗会議・工程の締めなどに備えた報告資料の準備。締め関連のランダムイベントの発生確率を下げる |

デイリー・モニタリング・サマライズは、キックオフ・クロージング・週次進捗会議といった
固定イベントのリスクもある程度下げる（レビューは対象外）。
それぞれの低減の度合いには差がある想定だが、具体的な配分は今後調整する。
これらのリスクが高まっている場面では、カード「臨時MTG」「臨時モニタリング」「臨時サマライズ」で
追加のカバーができる（詳細は [カード](../03-詳細設計/カード.md) を参照）。

これら4つはいずれも他のカードに入れ替え可能。
入れ替えた行動に対応するランダムイベントの発生確率はその分上昇するが、
そのリスクを承知の上で入れ替えるか、後で別のカードを使って挽回するかは
プレイヤーの判断に委ねられる。

入れ替えは基本的に当日限りの措置である。
翌日になると、4つの行動は自動的に元通りセットされ、
この自動復帰そのものには追加コストが発生しない
（残業許可などで1日のコスト上限を引き上げない限り、
ステージ開始時点でガントチャートに割り振られた範囲に収まる、という意味）。
入れ替え先のカードのコストが1日の上限を超える場合や、
効果が複数ターンにわたって持続する場合の扱いは別途検討する。

## メンバーの理想形（デフォルトの1日の行動）

メンバーの1日は基本、デイリーと自分が担当する工程のタスクにフルコミットする。
PMのように複数の行動へ内訳を分けることはしない。
