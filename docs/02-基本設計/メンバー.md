# メンバー

## パラメータ概要

メンバーは「技」「経験値」「心」「体」の4つのパラメータを持つ。

| パラメータ | 範囲 | 初期値 | 変動要因 | 効果 |
| ----------- | ------ | -------- | --------- | ------ |
| 技（レベル） | 0〜99 | ステージ依存 | 経験値が一定値に達するとレベルアップする形で上昇する。自然減少はしない | 高いほど進捗ダイスが計画値付近で「高止まり」しやすくなる |
| 経験値 | 0〜 | 0 | タスクをこなすことで蓄積する。技が低いメンバーほど蓄積が速い | 一定値に達すると技が1上がる。詳細は次項「技（レベル）と経験値」を参照 |
| 心 | 0〜150 | 100 | 毎ターンランダムに上下する。コミュニケーションイベント（雑談・個別面談・デイリー・モニタリング等）の回数や、進捗が順調に進むことでも上昇する。手戻り・停滞などのネガティブイベントが起きると下降する | 安定さを示すパラメータ。低すぎても高すぎてもネガティブイベントの発生要因となる。進捗ダイスそのものには直接影響しない。詳細は [イベント](../03-詳細設計/イベント.md) を参照 |
| 体 | 0〜100 | 100 | 毎ターンランダムに下がる（100を超えることはない） | 技を活かせるかどうかを示すパラメータ。低いとネガティブイベントの発生要因となり、進捗ダイスも下振れしやすくなる |

## 技（レベル）と経験値

技は、一般的なSRPGにおけるレベルに相当するパラメータ。
エンジニアの経験年数のようなものをイメージする。

- 技の最大値は99
- 標準メンバー4人のステージ開始時点の技は、10・8・6・4を1人ずつ割り振る
- 技を直接上げる手段はなく、経験値の蓄積により自動的にレベルアップする形でのみ上昇する
- 経験値はタスクをこなすことで蓄積する
- 技が低いメンバーほど、同じ量のタスクをこなした際に蓄積する経験値が多い（＝レベルが上がりやすい）
- ただし、一般的なSRPGと比べるとレベルアップの速度はかなり遅く、
  技4以下のメンバーでも1ヶ月ステージを通して1程度しか上がらない想定
- カード「教育」「ペアプログラミング」は、技を直接上げるのではなく、
  この経験値の蓄積を早めるブースト的な位置づけになる
  （具体的な付与量は今後調整。詳細は [カード](../03-詳細設計/カード.md) を参照）

## 心・体の回復手段

| 回復手段 | トリガー | 対象 |
| --------- | --------- | ------ |
| 週休2日 | 5ターン（稼働日）経過ごと | 全メンバー自動 |
| カード「計画休」 | PMが使用 | 指定メンバー1人 |
| ランダムイベント「休息」 | 発生確率に応じて発生 | 該当メンバー |
| カード「雑談」 | PMが使用 | 心の低下率を低減（回復ではなく減衰緩和） |

週末はデフォルトでは何も発生しない空白ターン。
カード「休出」を使うことで、一定期間は週末も進捗・イベントが発生するようになるが、
副作用が大きい。

## メンバー人数

- 標準人数は4人（1ヶ月ステージ〈PoC想定〉のみ標準2人）
- カード「メンバー追加」で追加・補充可能、最大6人
- 新規メンバーは「技」が低い状態で参加し、既存メンバーの誰かに
  強制イベント「オンボーディング」が発生する
- メンバーが2人以下の場合、離脱イベントは発生しない
