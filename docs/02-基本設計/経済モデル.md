# 経済モデル

## コスト体系

予算・工数・コストをすべて「コスト」という単一単位で表現する
（1時間＝1万円のイメージ）。金額表示はしない。

```
総消費コスト = ベースライン消費（Gantt計画に基づき自動進行、PMの行動有無に関係なく発生）
              + PMの行動コスト（カード使用分。1日の上限は基本8で、使わなくても節約にはならない）
              + 追加事象コスト（残業許可・手戻り対応・交渉など）

利益 = 予算 − 総消費コスト
```

- ステージ開始時点で、予算・ガントチャート・PMおよび各メンバーの日次コストは
  既に割り振られた状態で始まる
- ガントチャートには、メンバーのタスクに加えてPM自身の日次行動
  （理想形、1日8コスト分）も最初から記載されている
- 割り振られたベースライン消費は、通常はおおむね予算の7〜8割程度になる想定
- 計画通りに進めば、残りの2〜3割のバッファがそのまま利益になる
- ガントチャート全体のスケジュールバッファは、
  あらかじめ予算から取り崩して確保された「ダミータスク」として組み込まれている。
  実際の作業に消費されずに残れば利益になり、
  手戻りや延伸などで実タスクに置き換わって消費されれば、その分利益が減る

## カード使用時のコストの出しどころ

事前に割り振られた行動（PMの理想形の行動、メンバーのタスク）と異なるカードを使う場合、
次の2通りの方法で実現する。

- 割り振られた行動を、使いたいカードに入れ替える
  （コストの総量は変わらないため、利益への影響はない）
- 割り振りを崩さず、必要なコストをバッファから直接払う（利益予定分が削られる）

「残業許可」のように1日のコスト上限自体を引き上げる（例: 8→10）カードは、
その拡張分をバッファから取り崩すことで実現する
（使える行動量が増える代わりに利益が削られる）。
