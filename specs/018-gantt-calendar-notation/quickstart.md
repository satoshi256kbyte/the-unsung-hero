# Quickstart: docsガントチャート表記見直し（カレンダー列形式）

## 前提

- `public/data/stages/poc-01.json`が最新の状態であること（Spec-16実装済み）

## 検証

```bash
npm run lint:md
```

- markdownlint-cli2がエラー0で終了すること
  （テーブルはMD013の行長チェック対象外のため、30列の表でもエラーにならない）

## 手動確認

1. `docs/03-詳細設計/ステージ/PoCステージ01.md`を開く
2. ヘッダーテーブルの「締切ターン」が`public/data/stages/poc-01.json`の
   `deadline`（30）と一致することを確認する
3. ヘッダーテーブルの「初期カード」に`initialCards`の5枚
   （デイリー・レビュー・モニタリング・休出（土）・休出（日））が
   すべて含まれることを確認する
4. ガントチャート表の列見出しがターン1から30まで「ターン番号(曜日)」
   形式で連続していることを確認する
5. 任意のタスク行（例: t01 要件定義、startTurn=1, duration=3）について、
   ターン1〜3のセルが`■`、それ以外が空欄であることを確認する
6. 土日をまたぐタスク行（例: t02 UI設計、startTurn=4, duration=3、
   ターン4〜6が該当し、ターン6は土曜）について、平日セルが`■`、
   土日セルが`・`になっていることを確認する
7. 条件付きイベント表のターン番号が`public/data/stages/poc-01.json`の
   `conditionalEvents[].turn`（5, 12, 16, 22, 24）と一致することを確認する
8. 表の下に凡例（`■`=平日稼働、`・`=期間内だが土日のため非稼働）が
   記載されていることを確認する
