# Quickstart: 週モデル変更（ターン＝暦日・7ターン周期）

## 前提

- `npm install`済み

## 検証

```bash
npm run typecheck
npm run test
npm run test:e2e
```

- `typecheck`がエラーゼロで終了すること
- `src/game/calendar.ts`の`isWeekend`が全曜日パターンで正しく判定することを
  単体テストで確認する
- 既存の単体テスト・E2Eテストが週モデル変更を反映した上で全件PASSすること

## 手動確認

1. `npm run dev`で開発サーバーを起動する
2. 6日目（土曜、`(turn-1)%7===5`）まで休日出勤カードを使わずにターンを進め、
   その日のタスク進捗が発生しないことを確認する
3. 休日出勤（土）カードを手札から選び、カード枠にドロップする
4. 対象メンバー選択のオーバーレイが表示され、メンバーを選ぶ
5. ターンを確定し、選択したメンバーのタスクだけその土曜に進捗することを確認する
6. 画面上の表示が「ターン」ではなく「◯日目」になっていることを確認する
