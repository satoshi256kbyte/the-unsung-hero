# Quickstart: タイトル〜ステージセレクト画面遷移

## 前提

- `npm install`済み

## 検証

```bash
npm run typecheck
npm run test
npm run test:e2e
```

- `typecheck`がエラーゼロで終了すること
- 既存の単体テスト・E2Eテストが変更なく全件PASSすること

## 手動確認

1. `npm run dev`で開発サーバーを起動する
2. ブラウザでアクセスし、タイトル画面（ロゴ＋スタートボタン）が表示されることを確認する
3. スタートボタンを押し、ステージセレクト画面（ステージ一覧）が表示されることを確認する
4. ステージカードをクリックし、確認画面（プロジェクト概要・予算・目標利益率）が
   表示されることを確認する
5. 「もどる」を押し、一覧表示に戻ることを確認する
6. 再度ステージを選び「開始する」を押し、ゲームプレイ画面が始まることを確認する
