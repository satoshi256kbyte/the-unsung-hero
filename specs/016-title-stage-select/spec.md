## User Scenarios & Testing

### User Story 1 - タイトル画面からゲームを始められる (Priority: P1)

PMがゲームを起動すると、タイトル画面が表示される。スタートボタンを押すと
ステージセレクト画面に進む。

**Why this priority**: 画面遷移フロー全体の起点。これがないと後続の
ステージ選択・確認自体に到達できない。

**Independent Test**: ゲームを起動し、タイトル画面が表示され、
スタートボタン押下でステージセレクト画面に遷移することを確認できる。

**Acceptance Scenarios**:

1. **Given** ゲームを起動した直後、**When** データのロードが完了する、
   **Then** タイトルロゴとスタートボタンが表示される
2. **Given** タイトル画面が表示されている、**When** スタートボタンを押す、
   **Then** ステージセレクト画面に遷移する

---

### User Story 2 - ステージの内容を確認してからプレイを開始できる (Priority: P1)

PMがステージセレクト画面でステージを選ぶと、そのステージのプロジェクト概要・
予算・目標利益率（クリア条件）を確認できる確認画面が表示される。内容に納得したら
「開始する」を選んでゲームを開始する。気が変わったら「もどる」でステージ一覧に戻れる。

**Why this priority**: ステージ内容を把握しないまま開始してしまうことを防ぐ、
本Specの中核価値。US1と並ぶ最優先。

**Independent Test**: ステージセレクト画面でステージカードをクリックし、
確認画面にプロジェクト概要・予算・目標利益率が表示されること、
「もどる」で一覧に戻れること、「開始する」でゲームが始まることを確認できる。

**Acceptance Scenarios**:

1. **Given** ステージセレクト画面が表示されている、**When** ステージカードを
   クリックする、**Then** 選択したステージの確認画面が表示される
2. **Given** 確認画面が表示されている、**When** 内容を確認する、
   **Then** プロジェクト概要・予算・目標利益率（率のみ、具体的な達成金額は
   表示しない）が表示されている
3. **Given** 確認画面が表示されている、**When** 「もどる」を押す、
   **Then** ステージ一覧表示に戻る
4. **Given** 確認画面が表示されている、**When** 「開始する」を押す、
   **Then** 選択したステージでゲームプレイ画面が始まる

---

### Edge Cases

- 選択可能なステージが1件のみの場合でも、一覧表示→確認表示の2段階の流れは
  省略しない（将来ステージが増えても導線を変えずに済むようにするため）
- 確認画面から「もどる」を選んだ場合、直前に選んでいたステージの選択状態は
  クリアされ、一覧表示に何も選択されていない状態で戻る

## Requirements

### Functional Requirements

- **FR-001**: システムは、ゲーム起動後（データロード完了後）にタイトル画面を
  表示しなければならない
- **FR-002**: タイトル画面はロゴ表示とスタートボタンのみで構成されなければならない
- **FR-003**: システムは、タイトル画面のスタートボタン押下時にステージセレクト画面へ
  遷移しなければならない
- **FR-004**: システムは、ステージセレクト画面で選択可能な全ステージを一覧表示
  しなければならない
- **FR-005**: システムは、ステージ一覧からステージが選択されたとき、そのステージの
  確認画面（プロジェクト概要・予算・目標利益率を含む）を表示しなければならない
- **FR-006**: 確認画面に表示する目標利益率は達成すべき率のみとし、
  予算から計算される具体的な達成金額を表示してはならない
- **FR-007**: システムは、確認画面で「もどる」が選ばれたときステージ一覧表示に
  戻らなければならない
- **FR-008**: システムは、確認画面で「開始する」が選ばれたとき、選択された
  ステージでゲームプレイを開始しなければならない
- **FR-009**: 各ステージは、確認画面に表示するためのプロジェクト概要文を
  持たなければならない

### Key Entities

- **Stage（確認画面表示用の追加属性）**: 既存のステージデータに
  プロジェクト概要文を表す属性が追加される。予算・目標利益率は既存のステージ・
  ゲーム設定データから参照する

## Success Criteria

### Measurable Outcomes

- **SC-001**: プレイヤーは起動からゲームプレイ開始までの間に、必ずステージの
  プロジェクト概要・予算・目標利益率を確認する機会を持つ（スキップして
  いきなり開始することはできない）
- **SC-002**: 確認画面で「もどる」を選んだ場合、100%の確率でステージ一覧表示に
  戻り、意図せずゲームが始まってしまうことがない
- **SC-003**: 既存の単体テスト・E2Eテストが変更なく全件PASSする
  （画面追加が既存のゲームロジックの挙動に影響しないこと）

## Assumptions

- タイトル画面には設定・クレジット等の追加メニューは含まない（将来必要になれば
  別Specで追加する）
- ステージ確認画面は独立したScene ではなく、ステージセレクト画面内の別表示状態
  として実現する（画面遷移の実装方式は`/speckit-plan`で確定する）
- ステージのプロジェクト概要文の具体的な文言は、実装時にステージデータへ追記する
- 目標利益率の値そのもの（現在のチューニング値）は本Specでは変更しない。
  ADR-022の方針に従い、表示元は既存の設定データを参照する
